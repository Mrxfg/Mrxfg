<summary><b>📋 Self-Hosted Stats Cards</b> — click to expand setup guide</summary>

<br>

The stats cards above use the **public** `github-readme-stats` API. For reliability and full theme control, deploy your own instance:

1. **Fork** [anuraghazra/github-readme-stats](https://github.com/anuraghazra/github-readme-stats) (keep it private)
2. **Create a Personal Access Token** on GitHub:  
   `Settings → Developer settings → Personal access tokens → Fine-grained tokens`  
   Scopes: only `Repos: Public` (read-only) is needed.
3. **Deploy on Vercel**:  
   Import your fork → set environment variable `PAT_1` to your token → deploy
4. **Custom theme** (optional — paste into your Vercel dashboard via `vercel.json` or env):

```json
{
  "env": {
    "GITHUB_USERNAME": "Mrxfg"
  }
}
```

5. Replace the image URLs in this README:
   - `https://github-readme-stats.vercel.app/...`  
     → `https://your-app-name.vercel.app/...`
